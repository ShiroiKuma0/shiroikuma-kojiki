# Fork (白い熊 考直) — Snooping panel matcher list.
# One glob per line. '*' matches any run of characters. Lines beginning with '#'
# and blank lines are ignored. A plain domain (no '*') also matches its subdomains.
#
# Aggressive set: high-confidence telemetry / ad / tracking / attribution / crash /
# session-replay / OEM domains. A match flags the lookup as a suspected snoop in the
# panel (it does NOT block — blocking stays a user action / blocklist job), so erring
# broad here only surfaces more for review. TLD-blanket entries that would shadow core
# services (e.g. *.facebook.com, *.googleapis.com, *.icloud.com) are deliberately avoided.
